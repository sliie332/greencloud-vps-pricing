## 常见问题

**支持支付宝吗？** 支持。付款方式包括 PayPal、信用卡、支付宝和虚拟币，国内用户直接支付宝付款即可，不需要海外支付工具。

**Budget KVM 和 EPYC NVMe 怎么选？** 同为 $25/年，Budget KVM 给 4GB 内存 + 4TB 流量但用 SSD RAID-10（多为 E5v4 至强），EPYC 版是 2GB 内存 + NVMe 盘。跑数据库、频繁读写选 EPYC；跑站群、代理节点这类吃内存和流量的选 Budget KVM。

**到期不续费会怎样？** 到期后 1 天暂停、3 天终止，数据就没机会再捞了（重开要付 $5 重建费，且不保证能恢复）。账单在到期前 14 天开出，够时间决定续不续。

**东京的 IIJ 和 Softbank 版本有什么区别？** 配置和价格完全一样（都是 $48/年、750GB 流量），区别在回程路由。两家都是日本 Tier-1 运营商，具体哪个对你更快，用商家提供的测试 IP ping 一下再选，比看任何评测都准。
